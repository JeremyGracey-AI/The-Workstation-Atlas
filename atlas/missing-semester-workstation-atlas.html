1 · Course Overview + the Shell

lecture 1/12/26
Core mental model: programs are building blocks; text is the interface; pipes make them compose.
The lecture’s flow
A textual interfacethe shell runs programs — faster and more scriptable than any GUI
navigate
Move & lookcd · pwd · ls — absolute vs relative paths
discover
Find programs$PATH is a search list; which shows the winner
One-job toolscat · grep · sort · uniq · head · sed · awk

Pipes & redirects| chains stdout→stdin · > >> $( ) capture it
automate
Shell programsvariables, if · for · while, background jobs &
Everything downstream of this course is this one loop: find a tool → compose it → script it.

Referencesbranches are mutable pointers; HEAD is you
compose

merge · rebase · reset · revert · bisect · worktree — all reduce to moving pointers on the same graph.

The lecture’s flow — an isolation ladder, climbed as needs grow
S8Publishuv publish → PyPI / registries — strangers can install it
S7Orchestratedocker compose — services declared together
S6Configureenv vars & config out of code — deploy anywhere unchanged

S1Isolate envuv venv — dependencies stop leaking between projects
